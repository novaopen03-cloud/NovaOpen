# NovaOpen

Sito statico a pagina singola (HTML/CSS/JS). La vista 3D usa Three.js caricato da jsDelivr; se non si carica, viene mostrata la foto del kit.

## Pubblicare
Carica il CONTENUTO della cartella (non la cartella stessa) nella radice del repository: `index.html` deve stare in radice.

## Da completare
- Link di checkout nel pulsante "Acquista ora" (attributo `href` in `index.html`, id `cta`).
- Email, P.IVA e dati del titolare in `index.html` e `legale.html`.
- Far verificare i testi legali.
