# NovaOpen

Sito statico a pagina singola (HTML/CSS/JS, nessuna dipendenza) per il kit apriscatole elettrico + apribarattoli.

## Pubblicare su GitHub Pages
1. Carica tutti i file nella root del repository.
2. Settings → Pages → Source: `main` / root.

## Da completare
- Link di checkout nel pulsante "Acquista ora" (`script.js`, in fondo).
- Email, P.IVA e dati del titolare in `index.html` e `legale.html`.
- Far verificare i testi legali.
